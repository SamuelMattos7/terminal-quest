## Findings and fixes

- **General IP limit bypass on starts.** A route-specific Fastify rate limit replaces the global configuration. The regression `counts starts toward the general IP limit` returned 200 for request 61 before the fix. `requestLimits.ts` now applies the 60/min/IP hook independently of route-level user budgets. The two plugin instances have independent per-request markers, so both limits execute. Their bounded default stores remain local to the single server process.
- **Unbounded reset container churn.** `rate-limits resets before replacing the live sandbox` reproduced an eleventh successful reset. Starts and resets now each allow 10/min/authenticated user, at `preHandler` after authentication, in addition to the shared IP budget. Rejected resets preserve the current sandbox. Start and reset counters are separate; together they permit at most 20 launches/min/user, still subject to 60/min/IP, one active session, global capacity and TTLs. Cross-IP and shared-NAT tests protect user keying; the original user keying already passed that regression.
- **Missing socket Origin accepted.** Require an exact `PUBLIC_ORIGIN` match, including presence, before authentication or attachment. Tests cover absent, literal `null`, hostile domain, suffix spoof, wrong port and foreign cookie, with no session data or socket replacement. Non-browser clients must send Origin explicitly; this is browser cross-site protection, not a replacement for cookie ownership.
- **Invalid origin configuration.** Accept only HTTP(S) origins without credentials, non-root paths, queries or fragments. Canonicalize case, default port and trailing slash for the socket comparison and CSP.
- **Unsupported network configuration silently ignored by launches.** The launcher previously forced `none` and discarded sidecars. It now passes the declared values to the existing provider guard, which rejects LAN and sidecars before Docker acquisition. This adds no LAN functionality or capabilities.

The initial focused run reproduced the IP, reset and absent-Origin gaps (3 failures). Build verification also caught test-only TypeScript errors during fixture extraction; those were corrected before final validation.
